Snake Game is a simple and interactive arcade game developed using Python and Pygame. The player controls a snake using the keyboard and tries to collect food to increase the score. As the snake eats food, it grows longer, making the game more challenging.
Features
Simple and user-friendly interface
Smooth snake movement
Food collection system
Automatic score tracking
Snake growth after collecting food
Collision detection
Game-over functionality
Keyboard-based controls
Technologies Used
Python
Pygame
Controls
↑ – Move Up
↓ – Move Down
← – Move Left
→ – Move Right
How to Play

The main objective of the game is to collect as much food as possible while controlling the snake. Each time the snake collects food, the score increases and the snake becomes longer. The player must avoid hitting the boundaries or the snake's own body. The game ends when a collision occurs.

Installation

First, install Python on your computer. Then install the Pygame library using:

pip install pygame

After installing Pygame, run the Python game file to start playing.
